# Computer-Science-Career-Explorer
The Career Exploration Program is a Java-based decision-support application that guides users through a structured exploration of computer science career pathways. Using hierarchical decision-tree logic, the system evaluates user interests across domains such as software development, data science, systems engineering, cybersecurity, database management, and UX/UI design, generating personalized career recommendations and associated technical skill pathways.

The application is implemented using a modular architecture with dedicated methods for each career domain, enabling scalable expansion and maintainability. Core computer science concepts include arrays, switch statements, conditional branching, iterative control flow, user-input processing, and procedural decomposition. The program demonstrates the practical use of interactive recommendation systems, menu-driven interfaces, and rule-based decision algorithms within a command-line environment.
